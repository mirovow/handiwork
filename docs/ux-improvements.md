# UX Улучшения Для Схем

- Мне достаточно информации для решения задачи: да, я посмотрел изображение и текущие экраны `frontend/src/routes/+page.svelte`, `frontend/src/routes/gallery/+page.svelte`, `frontend/src/routes/workspace/[id]/+page.svelte`.
- Я понимаю где нужно сделать правки: да, большая часть UX улучшений относится к workspace, часть к созданию схемы и галерее.
- Я уверен, что эти правки не сломают другой функционал: да, если делать инкрементами и покрывать тестами текущие сценарии прогресса/палитры; риски в canvas-взаимодействиях и сохранении прогресса.
- Я могу предложить несколько вариантов решения проблемы: да, есть быстрые UX улучшения без изменения модели данных и более сильные улучшения с расширением данных схемы.
- Я понимаю, как по шагам решить задачу: да, начинать стоит с навигации и легенды, затем добавить режимы работы и материалы.
- Я понимаю, как сделать задачу за меньшее число шагов: да, первым инкрементом можно сделать только rulers + улучшенную палитру + фильтр по цвету.
- Я понимаю, как потратить меньше input/output токенов: да, сфокусировался на ключевых файлах и не исследовал backend без необходимости.
- Я понимаю, что еще можно сделать, если не получится решить задачу: да, можно сначала оформить UX-прототип на текущих данных без изменения API.
- Нужно провести самостоятельный ресерч: уже проведен минимальный ресерч по UI; дополнительных вопросов сейчас не нужно.

## Что Видно На Бумажной Схеме
- Сетка имеет координаты и крупные линии каждые 10 клеток. Это помогает быстро возвращаться к месту и сверяться с листом.
- Есть явный центр схемы и разбиение на листы/части. На фото центр и сгиб важны, потому что большая схема не помещается целиком.
- Легенда содержит не только цвет, но и символ, номер цвета, название цвета и тип стежка.
- Есть отдельные блоки для полного креста, полукреста, бэкстича, французских узелков и смешанных нитей.
- Есть инструкции по стежкам и список материалов. Это снижает тревожность перед началом и помогает закупиться.

## Приоритет 1: Навигация По Схеме
- Добавить координатные линейки сверху и слева в workspace: номера каждые 10 клеток, более жирные линии для десятков, отметка центра.
- Добавить мини-карту/overview в углу: прямоугольник текущей видимой области, быстрый переход по клику.
- Добавить кнопку "К центру" рядом с `+`, `-`, `Сброс`, потому что бумажные схемы часто начинают от центра.
- Добавить визуальное разбиение на страницы или секции 50x50/60x60 клеток, чтобы пользователь мог вышивать кусками.

## Приоритет 2: Легенда Как На Бумаге
- Расширить текущую "Палитру ниток" в `frontend/src/routes/workspace/[id]/+page.svelte`: показывать символ, цвет, код, название, количество крестиков и прогресс по каждому цвету.
- Добавить фильтр "покажи только выбранный цвет/символ" и приглушение остальных клеток на canvas.
- Добавить режим "следующий незакрытый символ" из выбранного цвета, чтобы не искать глазами по всей схеме.
- В галерее показывать не только общий прогресс, но и "осталось цветов/крестиков", чтобы легче выбрать, какую схему продолжить.

## Приоритет 3: Режимы Вышивания
- Разделить действия: "перемещение", "отметить готовое", "посмотреть нитку". Сейчас тап по клетке сразу меняет прогресс, а контекстное меню показывает нитку; на мобильном это может быть неочевидно.
- Добавить undo/redo последних отметок. Для вышивки это критично: случайный тап на canvas легко не заметить.
- Добавить выделение текущей строки/столбца и crosshair под пальцем/курсором.
- Добавить режим "закрашивать маркером": пользователь выбирает цвет и отмечает готовые клетки подряд без лишних переключений.

## Приоритет 4: Подготовка Материалов
- На странице создания схемы `frontend/src/routes/+page.svelte` после генерации показывать "лист закупки": палитра, номера ниток, примерное количество стежков по цвету, ссылки на покупку.
- В workspace добавить "Материалы" рядом с палитрой: ткань/канва, размер в крестиках, выбранная палитра, количество цветов.
- Для каждого цвета показывать статус "есть / купить / закончилась", чтобы сервис помогал не только вышивать, но и вести набор.

## Приоритет 5: Печать И Экспорт
- Добавить экспорт PDF в стиле бумажной схемы: сетка с координатами, легенда, инструкции, страницы с overlap.
- Добавить режим печати "символы без цветной заливки" для тех, кто вышивает с бумажного листа.
- Добавить экспорт прогресса/резервную копию, чтобы пользователь не боялся потерять много часов отметок.

## Быстрый Первый Инкремент
Самый полезный атомарный шаг: улучшить workspace без изменения backend-модели.

- Добавить координатные rulers, центр и жирную десятую сетку на canvas.
- Расширить панель палитры: код, название, цвет, количество стежков, прогресс по цвету.
- Добавить выбор цвета в палитре и подсветку/фильтрацию клеток этого цвета.
- Покрыть тестами открытие палитры, выбор цвета, изменение текста прогресса по цвету и отсутствие случайного toggle при масштабировании.

## Альтернативы
- Минимальный вариант: только визуальная навигация на canvas. Быстро, дешево, сразу улучшает вышивание больших схем.
- Средний вариант: навигация + легенда + фильтр по цвету. Я бы выбрал его как лучший UX/стоимость.
- Полный вариант: добавить материалы, PDF и секции страниц. Это сильнее как продукт, но требует больше данных, API и тестов.
